# Proposal

## Why

PC作業中に発生する突発的なタスク依頼や作業実績メモを、現在アクティブな作業を中断せずに即座にObsidianへ記録できる環境が必要です。
従来はObsidianウィンドウを探してフォーカスを移し、対象のノートを開いて手動で追記する必要があり、思考の中断やメモの記入漏れが発生していました。
Win+RのようにOSのどこからでも素早く呼び出せるランチャーUIを提供し、タスクの新規作成とデイリーノートへの作業ログ追記を最小限のキーボード操作で完結させることで、作業記録の即時性と継続性を高めます。

## What Changes

- **グローバルホットキーによるクイック起動ランチャー**: OS上のどのアプリケーションを実行していても、左手中心のキーバインド（例: Win+Shift+Q 等）で瞬時に前面に表示される軽量メモ画面を提供します。起動時のデフォルト画面は作業実績入力画面とし、即座にメモを入力開始できます。
- **タスク追加機能**: タイトル（ファイル名）、依頼者・締め切り（フロントマタープロパティ）、本文を入力し、指定したObsidian Vaultのタスクフォルダへ自動生成・配置します（完了日プロパティの初期化や、将来的な見積もり・重要度等のプロパティ追加に対応できる柔軟な設計）。
- **作業ログ（作業実績）追記機能**: メモ入力に特化した画面から、当日のデイリーノートの指定セクション（設定ファイルで走査対象見出しを指定可能、デフォルト: `## 作業ログ`）へ時系列でタイムスタンプ（`hh:mm` 形式）付きの作業ログを追記します。当日分のデイリーノートが存在しない場合は、Obsidianのコアプラグイン設定（`.obsidian/daily-notes.json`）のテンプレートおよびフォルダ・日付書式に従って自動生成します。
- **モード切り替えUI**: 同一のランチャーウィンドウ内で、ショートカットまたはタブ切り替えにより「作業実績入力（初期状態）」と「タスク追加」を素早く切り替えられるインターフェースを提供します。
- **設定管理**: 対象のObsidian Vaultパス、タスク保存先フォルダ、Obsidianコアデイリーノート設定の自動連携、作業ログ走査見出し、ホットキーなどの設定を永続化・管理する仕組みを提供します。

## Capabilities

### New Capabilities
- `quick-launcher`: OSグローバルホットキーの登録、軽量ポップアップウィンドウの表示/非表示切り替え、および作業実績（初期表示）/タスクのモード切り替えUI。
- `task-capture`: Obsidian Vault内のタスクフォルダに対する個別タスクノートの生成、フロントマタープロパティ（依頼者、期日、完了日、将来の拡張プロパティ）の埋め込み、および本文書き込み。
- `worklog-capture`: Obsidianコア設定に基づく当日デイリーノートの自動検出・テンプレートからの生成、指定見出しセクションへの時系列ログ（タイムスタンプ + 複数行メモ）の追記。
- `config-management`: Obsidian Vaultのパス、タスクフォルダ名、Obsidianコアプラグイン（`.obsidian/daily-notes.json`）連携、作業ログ走査見出し、ホットキー割り当て、タスクプロパティ定義の保存と読み込み。

### Modified Capabilities
None.

## Impact

- **依存関係/ランタイム**:
  - グローバルホットキー登録（Windows API `RegisterHotKey`）および軽量・低リソースなUI（Tauri/WebView2 または C# WPF 等）の採用。
  - Obsidian VaultのローカルMarkdownファイルシステムおよび `.obsidian/daily-notes.json` への直接読み書き。
- **データ形式**:
  - Obsidianの標準Markdown（YAML frontmatter）に準拠したタスクファイル。
  - Obsidianコアプラグイン設定（`.obsidian/daily-notes.json`）に準拠したデイリーノートおよび指定セクションへの機械可読ログ（WebVTT形式類似）。
- **既存システムへの影響**:
  - Obsidian本体は起動していなくてもローカルファイルとして書き込みが可能であり、Obsidian起動時に自動反映されます。
